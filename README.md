I'm a full-stack engineer with **5+ years** of experience building production systems end to end, from the database schema and async workers to the React UI and the AWS infrastructure underneath.

Right now I'm a Software Engineer at **LawnStarter**, where I own backend services and internal platforms for the Growth org. Most of my work turns slow, manual workflows into reliable software built on **Python**, **TypeScript**, **PostgreSQL**, **Redis** and **LLMs**.

I care about clean code, honest observability and systems that keep running when nobody is watching.

## Recent Work

- Built an **in-house AI content platform** (FastAPI, PostgreSQL, Redis workers, Next.js) that replaced a paid third-party tool, and cut failed-run recovery cost **~44x** with targeted, feedback-driven repairs
- Designed a **data-verification agent** across 22 public data sources (EPA, CDC, Census) that auto-verifies **99%** of published research data and replaced manual review by **6 people**
- Built a **self-healing nightly ingestion pipeline** on GitHub Actions with run locks, retries and catch-up runs that operates zero-touch and replaced **2 manual roles**
- Shipped **public cost calculators** on Cloudflare Workers with ZIP-level pricing for **11,000+ ZIP codes** and a self-updating daily energy-price feed
- Built a **multi-tenant AI email app on AWS** (NestJS, React, Aurora PostgreSQL, BullMQ on ECS Fargate) with AI features on Amazon Bedrock and health-gated, auto-rollback deploys
- Cut analytics recompute time from **4.4s to 0.58s** by replacing a full sweep with event-driven updates of only the records that changed
